# MXGE Loader 0.5.0-beta.1

Experimental companion. Downloads from supported public links are not yet verified on physical devices.

**هوية مستقلة وتجربة مشاركة أسرع:**

- ألوان بترولي وبرتقالي ونعناعي، مع أيقونة وأزرار تنقل أصلية مختلفة عن MXGE Player. الرئيسية تركّز على اللصق/البحث، وبطاقات الملفات والإعدادات مجمعة بوضوح.
- من إنستجرام أو تطبيق يدعم مشاركة الروابط: **مشاركة ← MXGE Loader** تفتح Activity شفافة على هيئة لوحة تنزيل سفلية فوق التطبيق الأصلي، بدل فتح صفحة Loader الرئيسية. اختار الجودة واضغط «تنزيل دلوقتي»؛ تُضاف المهمة لخدمة التنزيل ثم تُغلق اللوحة للعودة للتطبيق الأصلي.
- تبويبا فيديو/صوت يعرضان الجودات الحقيقية فقط، مع اختيار مقترح قريب من 720p إن كان متاحًا، وزر تنزيل ثابت ومكان حفظ واضح. كل الجودات والصيغ المتاحة تظل قابلة للاختيار.
- اختيار اللوحة لا يحتاج إذن الظهور فوق التطبيقات ولا فقاعة دائمة. يمكن إغلاقها لإلغاء استخراج الرابط؛ الدوران يعيد ضبط حجمها، والمحتوى الطويل قابل للتمرير. المهمة المحفوظة تُحتفظ بها إن منع Android بدء الخدمة، مع طريق واضح لفتح التنزيلات دون إضافة نسخة مكررة.

Install over existing Loader/Links without uninstalling: same `io.github.mxge25.linkaudio` and signing certificate, code **6**. The download engine remains the same pinned official yt-dlp 2026.10.21 from 0.4.1. The user reported the previous version downloading successfully; the new cross-app sheet has not been exercised on an attached physical phone. Native compilation/lint and APK packaging checks are separate from device UX verification.

Android 8+ ARM devices with **4 KiB memory pages**. The existing 16 KiB runtime limitation remains. Public sources may restrict requests or require a session; this app does not collect sign-in/cookies. No internal browser, app ads, account, backend or analytics. App-library files remain tied to installation; choose a folder for independent retention.

All three signed APKs, companion-only source ZIP and SHA256SUMS.txt accompany this release. Original vector/UI assets and existing licensed fonts only; no competitor code, branding or artwork. Matching source includes licenses and unresolved native-producing-build provenance directions. **Player source remains PRIVATE and Player stays offline.** Player build 9 and all previous releases are retained.
