# MXGE Scanner 0.1.0 Beta 1 — ماسح المستندات الأوفلاين

First Android beta of MXGE Scanner. Camera and OCR have not been verified on a physical Android device.

- Scan or import pages, adjust the crop and perspective, rotate and enhance them, and export to PDF, JPG, or text.
- Fully offline Arabic and English OCR powered by on-device Tesseract.
- On-device edge detection with OpenCV and CameraX integration.
- Document library with tags, favorites, trash, draft recovery, and merge/extract tools.
- Completely offline: no INTERNET permission requested or used.

## المميزات الرئيسية
- تصوير مستندات مفردة أو دفعات، واستيراد الصور والـ PDF كصفحات قابلة للتحرير.
- كشف الحواف وقص المنظور بأربع نقاط، والتدوير، وفلاتر تحسين المستندات.
- استخراج النصوص (OCR) بالعربية والإنجليزية بدون اتصال بالإنترنت بالكامل وبدون أي خوادم خارجية.
- تصدير بصيغ PDF قابلة للبحث، صور عادية، ونصوص مستخرجة TXT.
- إدارة المستندات: وسوم، مفضلة، سلة مهملات، دمج، واستخراج الصفحات، مع حفظ تلقائي للمسودات.
- حماية تامة للخصوصية: التطبيق أوفلاين بالكامل، بدون إعلانات، بدون حسابات، وبدون إذن الإنترنت.
