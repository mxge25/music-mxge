MXGE Loader 0.7.0-beta.1 preserves the Links/Loader package/signing identity. It also reduces repeated UI work and uses lossless APK compression without removing features. It supplies direct YouTube search, paste/share, source-provided MP4/M4A/MP3 choices and background downloads, without an internal browser. A concise midnight/periwinkle/lime UI and original split-wing icon accompany default public media saves in Movies/MXGE Loader (video) Music/MXGE Loader (audio) and Pictures/MXGE Loader (public post photos); older private files can be exported from My files. Custom folders remain available. Android 8/9 alone may request the SDK-capped legacy write grant; newer Android saves owned media without a storage grant. Public-photo source data must be exposed by Instagram/Facebook; restricted/login-only responses can fail. UI, Gallery, photo service downloads and background behavior remain unverified on a phone. The runtime requires 4 KiB pages; 16 KiB pages are unsupported. Player remains offline and private. See Loader release notes and companion SOURCES.md for limits.

The website defaults to the smaller ARM64 APK, with an ARMv7 alternative. Both have identical features/payloads for their ABI; Universal remains a historical Release asset after a user-reported installation failure. Source/license/checksum links are omitted from the download UI; those files remain in Releases. Download signed APKs and SHA256SUMS.txt from Releases. GitHub Pages enables each app's buttons only after its exact published assets verify; companion downloads also require its source ZIP. Existing older release assets remain available. Website fonts are locally hosted under OFL; no external scripts or tracking.
