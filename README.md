# MXGE Player · مشغّل صوت دون إنترنت

مشغّل أندرويد مجاني بواجهة عربية وإنجليزية، دون إعلانات أو حساب أو إذن إنترنت أو ميكروفون.

**1.0.0-beta.1 — لم يُختبر على أجهزة فعلية بعد. أداة القص تجريبية.**

An original, entirely offline Flutter audio player for Android 8+. Free forever, no ads or paywall.

**Not yet verified on physical devices. The cutter is experimental.**

The source and bilingual download page are being prepared for this repository. Signed APKs belong in GitHub Releases, never in the Git source history.
