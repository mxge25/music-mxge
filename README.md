## English

Public download page and signed release distribution for **MXGE Player**. **Android application source is private and is not included in this repository.**

Free forever, fully offline, no ads, account, paywall, analytics, internet or microphone permission. Arabic-first with English. Android 8+; ARM64 primary and ARMv7 alternative.

**Not yet verified on physical devices. The cutter is experimental.**

The landing page is static HTML/CSS/JS, uses locally bundled OFL fonts, and contains no external scripts or trackers. GitHub Actions deploys it to Pages and enables download buttons only after the exact pre-release APK assets and checksum file are public and their sizes/hashes verify. An unavailable download button means the release files have not been published yet.

Font license notices are in `site/assets/licenses/`. Release APKs belong in GitHub Release assets, never in this repository's Git history.
