MXGE Loader 0.4.0-beta.1 replaces MXGE Links while preserving its package/signing identity. It supplies direct YouTube search, public-link preview, source-provided MP4/M4A/MP3 choices, a foreground-service download queue and a local library, without an internal browser. Background behavior, downloads and codecs are not yet phone-verified. The companion requires internet and currently supports only 4 KiB-page devices; 16 KiB pages are unsupported. MXGE Player remains entirely offline. See the Loader release notes and companion SOURCES.md for compatibility and native producing-build provenance limits.
